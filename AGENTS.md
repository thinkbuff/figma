# AGENTS.md

Component library for Figma/FigJam plugin UIs: `packages/react` (React + Base UI
+ Tailwind v4) over shared tokens in `packages/theme`. `playground/` is a
consumer smoke test. Per-component migration reports live in
`docs/migration/<track>/`.

## Layout

- Tests live in `packages/<pkg>/tests/` mirroring `src/` (e.g.
  `src/components/x/x.test.tsx` → `tests/components/x/x.test.tsx`); shared
  helpers in `packages/react/tests/test-utils/`; never colocate tests in `src/`.
- React tests import sources via the `~` alias (`~/components/x/x`); theme and
  utils tests use relative `../src/...` paths.

## Verify

- `pnpm test` — unit + browser tests.
- `pnpm test:visual` — pixel-exact screenshot suite (207 baselines). CI does not
  run it; always run locally before finishing UI work.
- `pnpm typecheck`, `pnpm check`, `pnpm build`.
- `pnpm -F @thinkbuff/figma-react build-storybook` after component changes.

## Visual tests

- Baselines: `packages/react/tests/visual/__screenshots__/*-chromium-darwin.png`.
  `pnpm test:visual:update` rewrites them — inspect every changed image before
  committing; an update bakes whatever rendered, including bugs.
- Vite can serve stale styles: a "no diff" result may be a cached render, not a
  real match. The vrt scripts clear `node_modules/.vite` first. To verify a
  suspicious result, dump computed styles:
  `VRT_PROBE="<story id>" pnpm -F @thinkbuff/figma-react probe`.
- `pnpm vrt:diff -- [vitest args]` snapshots baselines, re-runs the update and
  lists which shots changed (before-copies under `$TMPDIR/figma-vrt-diff/`).

## Theme (`packages/theme`)

- `src/css/**` is generated by `pnpm generate:css` — edit `src/theme/`, never
  the output. CI fails on uncommitted drift.
- `--figma-color-*` values are injected by the Figma editor at runtime
  (`themeColors: true`); see `docs/figma-runtime-colors.md` to extract them.
- Register every new utility family in `packages/react/src/utils/cn.ts`
  (tailwind-merge groups) or `cn()` merges it into the wrong group.
- Elevation/shadow variables live in the per-theme blocks (`.figma-light`,
  `.figma-dark`, `.figjam`), not `@theme`, so nested `.figma-dark` resolves dark
  values.
- UI3 design reference: figma-kit `beta` @ `4366bb0` (MIT, clone to /tmp when
  needed). User screenshots override it.

## Components (`packages/react`)

- Base UI conventions: `render` prop (never `asChild`), `aria-expanded` for
  open-state styling, `addClassName` for callback classNames, `cn()` to merge.
- Prefer canonical Tailwind forms (`data-popup-open`, `inset-0.5`,
  `-top-1.25`) over bracket variants and arbitrary values.
- Component styles live in `packages/react/styles.css` under
  `@layer components`.

## Commits

- Conventional Commits (commitlint enforced); pre-commit runs `vp check --fix`
  on staged files.
- File names are kebab-case (`unicorn/filename-case` is an error); conventional
  uppercase files like `README.md` and `AGENTS.md` are the exception.
- Do not kill listeners on dev ports (Storybook uses 6006) you did not start.
